# rm-project-work-16
Sviluppo di una applicazione full-stack API-based per un’organizzazione del settore sanitario.

## Panoramica
Questo progetto contiene due parti separate:
- `backend`: applicazione Spring Boot (Java + Maven) che espone API REST per la gestione di Item.
- `frontend`: applicazione Angular (Standalone Components) che consuma le API e mostra gli Item.

## Prerequisiti
- Java 25
- Maven
- Node.js (versione LTS consigliata)
- npm o pnpm
